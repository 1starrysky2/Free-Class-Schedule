# 无课表工具

从课程表 Excel 中自动提取**无课时间**的本地小工具。上传教务系统导出的课表，按「星期 + 节次」计算每个时间段在哪些周空闲，方便安排自习、活动、面试或值班。

纯 Python 实现，本机运行，**不会上传任何数据到外部服务器**。

## 功能特性

- 读取 `.xlsx` / `.xls` / `.xlsm` 课表文件，支持 10MB 以内上传
- 识别多种周次写法（见下表），兼容全角/半角括号，一个单元格里的多段课程自动合并
- 自动计算每个时间段的无课周次，连续周合并输出（如 `1-8,11-16`）
- 文件预览、上传进度条、浅色/深色主题自适应
- 提供 HTTP 接口，方便接入自己的系统

## 快速开始

环境要求：Python 3.9 及以上。

```bash
pip install -r requirements.txt
python app.py
```

然后浏览器访问 <http://127.0.0.1:8001>，上传课表、设置总周数，即可得到无课时间表。

- 端口在 `app.py` 顶部的 `PORT` 常量中修改
- 停止服务：在启动它的终端按 `Ctrl+C`

## 课表格式要求

工具按教务系统标准导出格式解析：

| 位置 | 内容 |
| --- | --- |
| 第 1~2 行 | 说明/表头，跳过不读 |
| 第 3 行起 | 具体课程 |
| 第 1 列 | 备注列，遇到「其他课程」即停止统计 |
| 第 2 列 | 节次（1~12 的数字，两行并为一个时段：1-2、3-4 …… 11-12） |
| 第 3~9 列 | 星期一 至 星期日 |

### 支持的周次写法

| 格式 | 示例 | 识别为有课的周 |
| --- | --- | --- |
| x-y周(单/双) | `1-7周(单)` | 1, 3, 5, 7（双则取偶数周） |
| x周(单/双) | `8周(双)` | 第 8 周 |
| (xx节) x-y周 | `(3-4节) 1-16周` | 1~16 |
| x-y周 | `9-15周` | 9~15 |
| x周 | `16周` | 第 16 周 |

- 一个单元格包含多段课程（换行或逗号分隔）时，取各段有课周的并集
- 空单元格视为该时间段**整学期空闲**
- 总周数默认 16，可填 1~30；超出有课范围的周自动计入空闲

## 工作原理

1. **定位网格** —— 按「节次 × 星期」读取表格，每个时段只统计一次
2. **识别有课周** —— 5 条正则分别匹配上表中的写法，负向断言保证同一段文字不被重复计数（见 `model.py` 的 `WEEK_PATTERNS`）
3. **计算空闲** —— 总周数减去有课周，连续周合并成 `1-8,11-16` 样式输出

## HTTP 接口

适合想把空闲时间计算接入自己系统的开发者。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/process_schedule` | 上传课表并解析。浏览器表单直提返回 HTML 页面；带 `accept: application/json` 或 `x-requested-with: XMLHttpRequest` 头时返回 JSON |
| POST | `/api/preview_schedule` | 返回前 10 行 × 前 10 列的预览 JSON |

表单字段：`file`（课表文件）、`total_weeks`（总周数，可选，默认 16）。

```bash
curl -X POST http://127.0.0.1:8001/process_schedule \
  -H "accept: application/json" \
  -F "file=@课表.xlsx" \
  -F "total_weeks=16"
```

成功响应（HTTP 200）：

```json
{
  "code": 200,
  "msg": "ok",
  "file_name": "课表.xlsx",
  "total_weeks": 16,
  "total_count": 2,
  "data": [
    { "weekday": "星期一", "section": "3-4", "free_desc": "1-8,11-16" },
    { "weekday": "星期二", "section": "1-2", "free_desc": "1-16" }
  ]
}
```

失败时返回真实 HTTP 状态码（400/500），响应体为 `{"code": 400, "msg": "错误原因"}`。

## 常见问题

**启动报 `[Errno 10048]` 端口占用？**
已有实例在运行（或端口被其他程序占用）。先关掉旧进程，或改 `app.py` 里的 `PORT`。

**服务在跑，浏览器却打不开？**
检查系统代理是否拦截了 `127.0.0.1`。Chrome/Edge 默认不走代理访问本机；若使用代理软件，把 `localhost;127.0.0.1` 加入直连/绕过列表。

**提示「Excel 读取失败」？**
请上传教务系统原始导出的文件；手动删过列、合并过单元格会导致列位错位。文件损坏（并非真正的 Excel）也会报此错。

**某个周次写法没被识别？**
周次必须带「周」字（如 `1-16周`）。可运行 `python test_model.py` 查看已支持的格式；要新增写法，在 `model.py` 的 `WEEK_PATTERNS` 中加一条正则并补一条测试断言即可。
